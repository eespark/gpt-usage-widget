# GPT Usage Widget

영어 안내는 [영어 README](README.md)를 확인하세요.

Windows 작업표시줄에서 Codex의 남은 5시간·주간 한도를 확인하는 로컬 위젯입니다. 화이트·다크 모드, 알림, 사용 추이와 소진 예측을 지원합니다.

## 다운로드와 실행

1. Windows 64비트 PC에 Codex 앱 또는 CLI를 설치하고 본인의 ChatGPT 계정으로 로그인합니다.
2. [최신 릴리스](https://github.com/eespark/gpt-usage-widget/releases/latest)에서 원하는 언어의 ZIP을 받아 압축을 해제합니다.
3. 한국어는 `GPTUsageWidget.exe`, 영어는 `GPTUsageWidget.en.exe`를 실행합니다. 두 언어판 중 하나만 실행합니다.

.NET Framework 4.8이 필요하며 별도 .NET SDK나 관리자 권한은 필요하지 않습니다. 위젯은 설치된 Codex CLI의 로그인 상태를 사용합니다. 브라우저에서 ChatGPT에 로그인한 것만으로는 사용할 수 없습니다.

이 프로그램은 OpenAI의 공식 제품이 아닙니다. 표시 대상은 Codex 한도이며 ChatGPT 일반 채팅의 모든 모델별 한도를 보여주지는 않습니다.

## 사용하기

- 막대와 퍼센트는 남은 비율입니다. 5시간은 위쪽, 주간은 아래쪽에 표시합니다.
- 마우스를 올리면 상세 패널이 나타납니다. 소진 예측 카드를 누르면 사용 추이가 열리고, 패널 밖을 누르면 닫힙니다.
- 한 번 클릭하고 떼면 즉시 갱신합니다. 드래그하면 위젯 위치를 옮깁니다.
- 우클릭 메뉴에서 설정, 자동 실행, 종료를 선택합니다. 사라진 위젯은 트레이 메뉴의 **위젯 다시 표시**로 복구합니다.
- 설정에서 다크 모드, 글자·막대 크기, 표시 항목과 알림 기준을 바꿀 수 있습니다.
- 초기화 개수와 만료일은 계정에서 제공되는 경우 표시하며 D-7부터 강조합니다.

재설정 시각과 알림은 한국 시간(KST, UTC+9) 기준입니다. 기본 모니터에 표시하며 전체 화면 앱이나 숨겨진 작업표시줄에서는 위젯을 숨깁니다. 작업표시줄 버튼과 겹치면 위치를 조절하세요.

## 알림과 자동 갱신

설정에서 5시간·주간 잔량 알림 기준을 각각 선택할 수 있습니다. 기본은 20% 이하입니다. 재설정 전 알림의 기본값은 5시간 한도 60분 전, 주간 한도 전날 오후 12시 30분입니다. 같은 주기의 같은 알림은 반복하지 않습니다.

자동 갱신은 기본 60초이며 배터리 사용 시 120초입니다. 오프라인·절전·잠금 중에는 쉬고 복귀 후 다시 조회합니다. 조회 실패가 이어지면 재시도 간격이 최대 15분까지 늘어납니다. 수동 클릭으로 즉시 조회할 수 있습니다. PC나 위젯이 꺼져 있는 동안에는 기록과 알림을 수집하지 않습니다.

사용량 조회는 모델 추론을 요청하지 않으며 초기화권을 사용하지 않습니다.

## 사용 추이와 기록

사용 추이 오른쪽 아래에서 최근 24시간·7일·30일 등 표시 기간을 선택합니다. 마지막 선택은 재실행 후에도 유지됩니다. 5시간은 파랑, 주간은 보라입니다. 작은 원형 표시는 100% 시작점, 0% 종료점 또는 초기화 직전 값입니다.

조회 공백은 선으로 연결하지만 그 사이의 소비를 계산에 추가하지 않습니다. 24시간 화면의 막대는 시간별 소모량, 긴 기간의 막대는 선택 기간을 24구간으로 나눈 소모량입니다. `%p`는 퍼센트포인트로, 70%에서 60%가 되면 10%p를 소비한 것입니다.

기록 보관은 기본 90일이며 30·90·180·365일 중 선택합니다. 화면 표시 기간과 보관 기간은 별개입니다. 기록이 보이지 않으면 표시 기간을 늘려 확인하세요. 저장되지 않은 시간의 기록은 나중에 복원할 수 없습니다.

설정과 기록은 `%USERPROFILE%\.gpt-usage-widget\`에 저장되며 PC별로 관리됩니다. 자동 동기화하지 않습니다. 저장 시 이전 기록 파일을 백업합니다. 설정의 **사용 추이 기록 삭제**는 기록과 복구용 백업을 함께 삭제합니다. 보관 기간을 줄여 삭제된 기록은 기간을 다시 늘려도 복원되지 않습니다.

이전 버전의 저장소에 나뉘어 있던 기록은 업데이트 후 공통 저장소로 자동 통합합니다. 이전 원본은 삭제하지 않습니다.

위젯은 비밀번호·API 키·대화 내용을 저장하지 않습니다. 사용량 조회에는 기존 Codex 로그인과 인터넷 연결을 사용합니다.

## 소진 예측

**연속 작업 예측**은 현재 작업 강도로 쉬지 않고 사용할 경우 남은 시간을 보여줍니다. **주간 일수 예측**은 완료된 관측 날짜의 일평균 소비량을 기준으로 계산하며 연속 작업 예측과 독립적입니다.

평균 작업 시간은 소비가 관측된 구간에서 추정한 참고값입니다. 기록이 부족하면 예측을 보류하며, 실제 작업 종류나 조회 공백에 따라 오차가 생길 수 있습니다. 자세한 의미는 [예측 안내](분석%20기간과%20예측.md)를 확인하세요.

## 문제 해결

- 사용량이 나오지 않으면 Codex 로그인과 인터넷 연결을 확인한 뒤 위젯을 클릭합니다.
- CLI를 찾지 못하면 `CODEX_USAGE_CLI` 환경 변수에 `codex.exe`의 전체 경로를 지정합니다.
- 지난 기록만 보이면 마지막 조회 시각과 표시 기간을 확인합니다. 위젯이 실행되지 않은 시간은 수집하지 않습니다.
- 실행 파일은 서명되지 않았으므로 Windows나 기관 정책에서 실행을 제한할 수 있습니다. 신뢰하는 배포 파일인지 확인하고 기관의 안내를 따르세요.

## 소스에서 빌드

소스 폴더에서 PowerShell로 실행합니다. 빌드는 자동 검증도 수행합니다.

```powershell
.\build.ps1
.\build.ps1 -English
```

한국어·영어 실행 파일은 `bin`에 생성됩니다. 배포 ZIP과 SHA-256 파일은 다음 명령으로 `dist`에 만듭니다.

```powershell
.\package.ps1
```
